# Office Visitor & Appointment Management Dashboard (Excel)

## Project Overview

This project demonstrates how Microsoft Excel can be used to support front desk operations through data cleaning, analysis, and dashboard reporting.

The original Hotel Booking dataset was transformed into an Office Visitor Management scenario to simulate a real-world front desk environment.

---

## Business Goal

Create an Excel dashboard to monitor:

- Visitor appointments
- Appointment cancellations
- Visitor traffic
- Meeting room utilization
- Visitor types
- Office operations

---

## Tools

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- XLOOKUP
- Dashboard Design

---

## Dataset

Hotel Booking Demand Dataset
Business Scenario Adaptation
The original Hotel Booking dataset was adapted into an Office Visitor & Appointment Management scenario to demonstrate Microsoft Excel skills commonly used in administrative and front desk roles.
